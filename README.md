# PNG / JPEG 区域编辑工具

一个**纯前端、零依赖**的浏览器图片编辑器。打开 PNG 或 JPEG，框选任意区域，把选中的内容**删除**（透明 / 纯色 / 内容感知修复），或者**裁剪**到选区——所有操作都在浏览器里本地完成，图片不会上传到任何服务器。

---

## 它能做什么

- **区域删除**：框选一块内容，一键清除为透明、填充纯色，或用周围像素智能补上（去水印 / 去杂物 / 抠图）
- **裁剪**：复用选区，保留选区、裁掉其余；矩形硬裁，椭圆 / 套索保留形状（外透明）
- **常用比例裁剪**：自由 / 1:1 / 4:3 / 3:4 / 16:9 / 9:16，切到比例后拖手柄自动等比锁定
- **多种选区**：矩形、椭圆、自由套索，带 8 个手柄调整大小、可整体拖动
- **导出尺寸可选**：100% / 75% / 50% / 25% / 200% / 自定义宽高，导出前先缩放，方便压体积、做缩略图
- **中英文切换**：右上角一键切换，自动记住语言偏好
- **无损导出**：PNG 保留透明通道，JPEG 自动垫白底
- **撤销 / 重做**：最多 25 步，连裁剪后的尺寸也能还原

## 快速开始

### 方式一：直接打开（最简单）

双击项目里的 `index.html`，即可在浏览器中使用。

### 方式二：本地服务（推荐，避免个别浏览器对本地文件限制）

```bash
cd png-editor
python -m http.server 8123
# 浏览器访问 http://127.0.0.1:8123/
```

> 想一打开就载入某张图？在地址后加 `?img=图片路径`，例如：
> `http://127.0.0.1:8123/?img=samples/sample.png`

## 部署到子路径（如 `xxx.com/png-editor/`）

工具已做子路径适配，**无需改任何代码**，把整个 `png-editor/` 目录丢到站点对应路径即可。

- 所有资源（`style.css` / `app.js`）均使用**相对路径**引用，可部署在任意深度的子路径下。
- `index.html` 头部会**动态设置 `<base>`**，以当前页面所在目录为基准解析相对路径——因此 `xxx.com/png-editor/`（带斜杠）、`xxx.com/png-editor`（不带斜杠）、`xxx.com/png-editor/index.html` 三种访问方式都能正确加载资源。
- 纯前端、无后端接口、无写死的根路径（`/xxx`），静态托管（Nginx / OSS / COS / GitHub Pages / Vercel 等）直接上传即可。

**关于 `?img=` 参数**
- 推荐用**相对路径**：`?img=samples/sample.png` → 会正确解析为 `xxx.com/png-editor/samples/sample.png`。
- 以 `/` 开头会相对**站点根**（不随 base 变），子路径部署时需写全，如 `?img=/png-editor/samples/sample.png`；也可直接传完整 URL。

## 详细用法

### 1. 打开图片

- 点击「**打开图片**」按钮，选择本地 PNG / JPEG；
- 或直接把图片**拖拽**进工作区；
- 或通过 `?img=` 参数自动载入（见上方快速开始）。

### 2. 选择选区工具

| 工具 | 说明 | 操作 |
|------|------|------|
| ▭ 矩形 | 规整框选 | 拖拽生成；可拖 8 个手柄改大小、拖动内部整体移动 |
| ◯ 椭圆 | 椭圆区域 | 同矩形 |
| ✎ 套索 | 任意形状 | 按住自由描边，松开自动闭合 |

选区生成后可以：
- **拖动内部**移动选区
- **拖 8 个手柄**（四角 + 四边中点）缩放
- 圆形手柄为缩放点，方形手柄为移动 / 调整

### 3. 删除选中（三种模式）

先选好**删除模式**，再点「**删除选中**」（或按 `Delete`）：

| 模式 | 效果 | 适用场景 |
|------|------|----------|
| **透明** | 选区清为透明 | 去水印、抠物、做镂空（`PNG` 保留透明，**最常用**） |
| **纯色** | 用取色器颜色填充选区 | 盖掉背景、统一色块 |
| **修复** | 内容感知，从周围采样把那块补上 | 简单背景上的杂物 / 水印 |

> **关于「修复」模式**：采用 FMM 简化扩散算法（从选区边界向内逐层采样平均）。
> - 对**纯色、简单背景、水印**去除效果最好；
> - 复杂渐变背景可能有轻微色偏，这类场景建议用「透明」或「纯色」更干净；
> - 全透明底图做修复会缺采样源，已加提示，直接用「透明」模式即可。

### 4. 裁剪

点「**✂ 裁剪**」进入裁剪模式（自动套一个覆盖全图的矩形框），调整选区后用「**应用裁剪**」或 `Enter` 执行：

- **矩形选区** → 硬裁切，画布尺寸精确变成选区大小，无透明边；
- **椭圆 / 套索选区** → 用 `clip()` 保留形状，形状外变透明（导 PNG 保留镂空）。

裁剪时选区外会**变暗**、选区内透出原图，所见即所得预览裁完的样子。

**常用比例裁剪**：裁剪模式旁有「**比例**」下拉，可选 `自由 / 1:1 / 4:3 / 3:4 / 16:9 / 9:16`。

- 选好比例后，选区会**自动重置成一个居中的、符合该比例的最大框**；
- 之后拖动四角 / 四边手柄时，**宽高比自动锁定**，随手一拖就是标准比例，不用自己算；
- 想恢复随意裁剪，把比例切回「**自由**」即可。

快捷键注意：`Enter` 应用裁剪；`Esc` 退出裁剪模式（不会误删）；裁剪模式下 `Delete` 被禁用。

### 5. 撤销 / 重做

- `Ctrl+Z` 撤销，`Ctrl+Y`（或 `Ctrl+Shift+Z`）重做
- 撤销栈最多 25 步，**会连裁剪后的画布尺寸一起还原**

### 6. 导出（可选尺寸）

导出前先在「**导出尺寸**」下拉里选目标大小，再点导出按钮：

| 选项 | 含义 |
|------|------|
| 原图 100% | 按当前画布像素原样导出（默认） |
| 75% / 50% / 25% | 等比缩小，适合压体积、做缩略图 |
| 200% | 等比放大（插值放大，清晰度有限） |
| 自定义… | 手动填**宽 × 高**（默认填当前图尺寸，可改成任意值） |

- **导出 PNG**：保留透明通道，适合去背 / 镂空图
- **导出 JPG**：自动垫白底（JPEG 不支持透明），适合照片
- 缩放采用浏览器画布插值（高质量平滑），在**导出瞬间**完成，不改变工作区的编辑尺寸——你可以放心先按原尺寸修图，最后再选一个小尺寸导出。

### 7. 切换语言

点右上角的 **EN / 中文** 按钮即可在中文和英文之间切换，整个界面（按钮、状态栏、提示、标题）会同步切换，语言偏好存在浏览器本地，下次打开自动沿用。

## 使用小贴士

- 去水印优先用「透明」模式 + 矩形选区，导出选 PNG，最干净无副作用。
- 照片修瑕疵用「修复」模式，选区尽量小、紧贴目标，效果更自然。
- 想做圆形头像 / 异形贴图：用椭圆或套索选区 → 裁剪 → 导出 PNG，形状外自动透明。
- 操作错了别急，`Ctrl+Z` 一路退回，连裁错尺寸也能还原。

## 技术说明

- 纯前端实现，无第三方依赖、无网络请求，图片完全在本地处理。
- 画布缩放 / 平移只改 CSS 显示尺寸，不重设画布像素分辨率，避免内容被清空。
- 删除 / 修复基于 `ImageData` 逐像素处理；修复采用多源距离扩散（FMM 简化）算法。
- 撤销 / 重做基于 `ImageData` 快照栈，并携带画布宽高以支持裁剪还原。
- 中英文切换用一份 `I18N` 字典 + `data-i18n` / `data-i18n-title` 属性标记，`t()` 负责取值与占位符替换，偏好存 `localStorage`。
- 导出尺寸在临时画布上先 `drawImage` 缩放再 `toBlob`，不影响工作区画布。
- 比例裁剪对「拖动缩放手柄」做等比锁定（`applyResizeRatio`），保证任意拖动都维持目标比例。
